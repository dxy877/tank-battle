# 坦克大战 (Tank Battle)

一个纯 HTML / CSS / JavaScript 实现的经典坦克大战小游戏。单文件、零依赖，直接用浏览器打开 `index.html` 即可游玩。

## 玩法

- 控制我方金色坦克，消灭所有敌方坦克即可过关
- 保护底部中央的基地（老鹰）——基地被摧毁则游戏结束
- 砖墙可被子弹击毁，钢墙无法破坏；河流会阻挡坦克，但子弹可以飞越
- 消灭敌人或击毁砖墙有几率掉落道具

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 空格 / J | 射击 |
| P | 暂停 |
| M | 静音 |

## 道具

| 图标 | 效果 |
| --- | --- |
| ♥ | 增加一条生命 |
| ⛨ | 获得护盾 |
| ❄ | 冻结所有敌人 |
| ★ | 提升射速 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。
